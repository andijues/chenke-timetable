# 课表识别与校对

本轮依据两份本地课表的版面改进通用识别，没有将个人课程写死在解析器内。原文件、姓名、学号、识别原文和个人截图不进入公开仓库、测试样本或交付归档。

文字 PDF 按文字坐标和表格线分组，不依赖提取文本的先后顺序。合并单元格使用实际边界；长课程名、斜杠分隔的教师/场地信息保持在所属星期列。下一页没有星期标题时，仅在页面宽度相近、同列内容连续的条件下续接上一页底部；不会跳过空页串接。

扫描或轮廓字 PDF 在本机尝试方向校正，再按单元格 OCR，减少相邻列文字串读。识别进度按页面和单元格显示。中文及英文模型随安装包提供，不上传文件，也不需要识别服务。手机速度取决于页面数量和清晰度，识别期间请保持应用打开。

有明确时刻的课表使用原表时间，不用通用节次表覆盖；只写第几节的课表按当前设置换算，并提示核对学校作息。学期第一天仍需在设置中按学校校历填写，课程上的周次以该学期起点计算。

支持起止周、单双周和离散周次。同名、同地点的相邻节只有周次完全相同时才合并；不同周次的末节单独保留，所以识别项数量可能超过课程名称数量。页尾“其他课程”“未安排时间地点”的内容留在原文，不会被默认放到周一。

OCR 中无法可靠解析的周次会提示校对。仅当同课、同日、同地点的相邻节提供唯一一致参考，且周次文字只差一个字符时，才补全并明确标记。没有参考或参考有冲突时不自动补全。所有导入项均保持待确认，确认前不生成闹钟。

导入后请检查课程名、星期、教室、时刻/节次及周次，特别是 OCR 标记和跨页记录。学期与节次设置可先调整，再确认课程。缺失安排可手动添加，不需要反复导入。

公开回归文件由 `scripts/make-layout-fixtures.py` 独立生成，仅含虚构课程与教室：

- `layout-multipage-demo.pdf`：合并格、标题换行、单双周、跨页教室、无具体时刻与未排期页尾。
- `rotated-outline-demo.pdf`：侧转的轮廓文字、真实时刻列、重复教学班名、相邻节合并及跨页课程。

两份原课表的逐字段期望及检查明细只保存在本机忽略目录；交付报告仅记录匿名计数、通过情况和解析器代码哈希。
