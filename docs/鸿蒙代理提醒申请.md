# 晨课的代理提醒申请资料

应用：晨课（com.andijues.chenke）。用途为个人自用的本机课表，不使用服务器、云识别或收费服务。

## 申请原因

使用场景：个人自用课表，属于学习类提醒。用户导入课表并核对后，按当天第一门上午课程的时间，减去用户设置的提前分钟生成起床提醒。例如08:30上课、提前90分钟，07:00提醒。必须在应用退出或进程终止后由系统按时响铃，避免错过上课。
通知标题：该起床啦。
通知文本：课程名称 · HH:mm上课。
通知场景：用户主动开启自动起床提醒；无晨课、停课日、演示或未确认课程不发布。
通知频率：每个有晨课的日期最多1条，滚动安排未来28天；修改课表时更新已有计划，不重复累积。用户可选择两次5分钟稍后提醒；另有手动发起的1分钟测试，同一时间最多1条。

## 功能说明

1. PDF、图片在设备本地识别，导入后可修改名称、星期、时间、周次。
2. 用户填写学校学期日期与节次时间，支持单双周、停课和补课。
3. 起床提前量可调整，系统计划只使用已确认课程。
4. 鸿蒙代码声明 ohos.permission.PUBLISH_AGENT_REMINDER，通过 reminderAgentManager 发布具体日期 Calendar 提醒，使用闹钟声音通道。
5. 应用只查询、更新和撤销自己的提醒；不开启定位、通讯录、麦克风等能力。
