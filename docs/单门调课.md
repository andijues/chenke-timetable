# 按某一次课程调休

进入「设置 → 调课」，默认是「按课程」。选择**原上课日期**，再选择这一次要处理的课程。

- 仅停课：选「仅停这一次课」，保存。当天其他课程及这门课之后的周次照常。
- 改期：选「调整日期、时间或地点」，填写新日期、开始/结束时间与地点。允许移到同一天另一时段，也允许移到周末或该课程原定周次之外的日期。
- 原课程的单双周、起止周和第1周日期用于确定原日期是否有这一次课；调入按明确目标日期执行，不套用目标周的单双周限制。

保存前可查看原安排、新安排和受影响日期的起床时间。与其他课程重叠会提示核对；不会自动挤走其他课程。结束时间必须晚于开始时间；跨午夜的课应分成两个上课安排录入。

下方「已保存的调整」可修改或撤销。修改同一门课同一次安排会更新原记录，避免重复调入。调入课程在日程、下一节课和周课表中均可点击，进入这条调整。撤销后移除调入课程、恢复原日期的课，并重算起床计划。原课程本身的编辑仍作用于常规周次；删除原课程会同时清除它的调整记录。

「按整天」仍可整天停课/放假，或按其他星期的课表上课。同一天可以同时保留单门调整和整天规则；**全天停课优先**，因此有全天停课的目标日期不能直接接收新调课，应先撤销停课或换日期。如果保存调课后又把目标日设为全天停课，该日所有课程暂不显示；撤销全天停课后调入课恢复。原日期全天停课不撤销已移到其他日期的课程。

起床计划始终取实际日期的首次晨课，减去设定的提前量。例如周四08:30和10:30各有一门课，提前90分钟；只停08:30这门课后，周四起床从07:00改为09:00。若把它移到周五09:00且周五没有更早晨课，则周五起床为07:30。演示数据、未确认课程和关闭自动安排仍按原来的安全规则处理。

JSON备份保存单门调整；ICS课程日历导出只包含调整后有效的已确认课程。恢复备份会关闭自动闹钟，核对后再开启。已经交给外部系统时钟的旧闹钟需在时钟中管理，课表变化不能证明它已被删除。
